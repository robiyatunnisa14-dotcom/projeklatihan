Rekayasa Perangkat Lunak (RPL)

Tentang Jurusan RPL

Jurusan Rekayasa Perangkat Lunak (RPL) adalah jurusan yang berfokus pada pengembangan perangkat lunak berbasis web, mobile, dan desktop. Siswa akan belajar tentang logika pemrograman, desain antarmuka, hingga manajemen proyek digital.

Lulusan RPL memiliki peluang karir luas seperti software developer, web designer, UI/UX designer, maupun technopreneur di bidang teknologi.

Dokumentasi Kegiatan RPL

Siswa RPL sedang belajar pemrograman web menggunakan HTML, CSS, dan JavaScript.

Kerja sama tim dalam mengembangkan aplikasi berbasis sekolah untuk kebutuhan digitalisasi data.

Presentasi hasil proyek aplikasi oleh siswa RPL di depan guru dan teman-teman kelas.
